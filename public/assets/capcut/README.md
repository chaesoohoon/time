# CapCut visual assets

이 폴더는 `/capcut` 학습 페이지에서 사용하는 수업용 이미지 자리입니다.

1. `/capcut` 페이지의 `수업용 이미지 생성 프롬프트` 섹션에서 프롬프트를 복사합니다.
2. GPT Image 2 또는 사용 가능한 이미지 생성 도구에서 이미지를 만듭니다.
3. 카드에 표시된 권장 파일명 그대로 이 폴더 아래에 저장합니다.
4. 사이트를 새로고침하면 placeholder 대신 실제 이미지가 표시됩니다.

하위 폴더:

- `screenshots/`: 캡컷 화면 구조 설명 이미지
- `visuals/`: 개념 설명, 흐름, 타임라인, 인포그래픽
- `practice/`: 실습 결과 미리보기
- `ai/`: AI 기능 설명 이미지
- `before-after/`: 편집 전/후 비교 이미지
- `thumbnails/`: 썸네일 또는 첫 장면 이미지
